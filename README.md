# 📍 Քիփս (Qips) - Telegram Mini App

Ժամանակակից, ինտերակտիվ և հզոր **Telegram Mini App (TMA)**, որը թույլ է տալիս տեսնել Ձեր մոտակայքում (10 մետրից մինչև մի քանի կիլոմետր) գտնվող մարդկանց, նրանց կոնտակտները, կարգավիճակը և անմիջապես նամակ գրել նրանց:

---

## ✨ Հիմնական Հնարավորությունները

### 1. 📡 Կախարդական Ռադար (Sonar Radar)
- Շրջանաձև պտտվող սոնար ճառագայթ (Sonar Sweep) և իրական հեռավորության օղակներ (50մ, 100մ, 250մ, 500մ):
- Ինտերակտիվ կետեր (blips). սոնարի ճառագայթը մարդու վրայով անցնելիս առաջանում է լուսային ալիք և ձայնային ազդանշան (sonar ping):
- Կարգավորվող շառավիղ (100մ - 2500մ) սահիկի միջոցով:

### 2. 🗺️ Ինտերակտիվ Քարտեզ (Dark Matter Map)
- Ինտեգրված **Leaflet** քարտեզ մուգ ժամանակակից ոճով:
- Ձեր դիրքը նշող ճառագայթող GPS փին (pulsing beacon) և որոնման շրջանագիծ:
- Մոտակա մարդկանց մարկերներ՝ իրենց նկարներով, առցանց կարգավիճակով և հեռավորության նշիչով:
- Մարկերին սեղմելիս բացվում է մարդու ամբողջական պրոֆիլը:

### 3. 📋 Կոնտակտների Ցուցակ և Ֆիլտրեր
- **Ֆիլտրեր**՝ «Բոլորը», «Առցանց», «Մոտակա (<100մ)», «Տեխ / IT», «Սոցիալական»:
- Որոնման տող՝ անունով, հետաքրքրություններով, հեշթեգերով կամ username-ով:
- Տեղեկատվական քարտեր՝ անուն, @username, հեռավորություն, կարգավիճակ, հոբբիներ:
- Արագ գործողություններ՝ **«Նամակ գրել»** և **«Դիտել պրոֆիլը»**:

### 4. 💬 Զրուցարան (In-App Instant Chat)
- Ներկառուցված արագ մեսենջեր:
- Իրատեսական խելացի պատասխաններ հայերենով (typing indicator-ով՝ «գրում է...»):
- Պատրաստի արտահայտություններ (icebreakers)՝ *«👋 Ողջույն, մոտակայքում ես?», «☕ Սուրճի՞ կգնանք Cascade-ում»*:
- Տոնական էֆեկտներ (confetti) և ձայնային ազդանշաններ (տեղեկացումներ, ուղարկված նամակի ձայն):

### 5. ✈️ Ուղիղ Կապ Telegram-ում
- «Բացել Telegram-ում» կոճակ, որն ուղիղ բացում է տվյալ մարդու հետ չատը Telegram հավելվածում (`https://t.me/username`):
- «Ողջունել 👋» կոճակ՝ կոնտակտը կիսելու համար:

### 6. 📍 Դիրքի Ճշգրտում (GPS և Երևանի Վայրեր)
- Կոճակ՝ **«Ակտիվացնել Իրական GPS-ը»** (օգտագործում է հեռախոսի Geolocation API-ն):
- Երևանի նախապես պատրաստված վայրեր՝ **Հանրապետության Հրապարակ**, **Կասկադ**, **Օպերա**, **Հյուսիսային Պողոտա**:

### 7. 🌐 Լեզուների և Կարգավորումների Ընտրություն
- Երկլեզու համակարգ՝ 🇦🇲 **Հայերեն**, 🇬🇧 **English**:
- Տեսանելիության կարգավորում (տեսանելի եմ ռադարում / Թաքնված Ghost ռեժիմ):
- Ձայնային էֆեկտների անջատիչ:
- Տելեգրամի BackButton-ի և Haptic Feedback-ի լիարժեք աջակցություն:

## 🛠️ Տեխնոլոգիական Կույտը (Tech Stack)

- **Frontend**: HTML5, Vanilla Modern CSS, JavaScript (ES Modules), Leaflet.js, Canvas Confetti
- **Build Tool**: Vite 8
- **Backend / Real-time**: Node.js, Express, WebSocket (`ws`)
- **Telegram WebApp SDK**: `https://telegram.org/js/telegram-web-app.js`

---

## 🚀 Ինչպես Գործարկել Տեղում (Local Setup)

### 1. Տեղադրել կախվածությունները
```bash
npm install
```

### 2. Գործարկել Development սերվերը
```bash
npm run dev
```
Բացեք ձեր բրաուզերում `http://localhost:5173` կամ Telegram Mini App-ի մեջ:

### 3. Կառուցել արտադրական տարբերակը (Production Build)
```bash
npm run build
```

### 4. Գործարկել WebSocket սերվերը (Live Peer Sync)
```bash
npm run server
```

## 🤖 Ինչպես Միացնել Telegram Bot-ին (@BotFather)

1. Բացեք Telegram հավելվածը և գրեք **[@BotFather](https://t.me/BotFather)**:
2. Ուղարկեք `/newbot` հրամանը, նշեք բոտի անունն ու username-ը:
3. Պատճենեք ստացված **API Token**-ը:
4. Ուղարկեք `/newapp` հրամանը BotFather-ին՝ Mini App ստեղծելու համար:
5. Նշեք Ձեր WebApp-ի URL-ը (օրինակ՝ Vercel-ի կամ Ngrok-ի հղումը):
6. Կարող եք նաև օգտագործել նախագծի մեջ գտնվող `bot.js`-ը՝
   - Պատճենեք `.env.example`-ը `.env`-ի մեջ՝
     ```bash
     cp .env.example .env
     ```
   - Լրացրեք `TELEGRAM_BOT_TOKEN` և `WEBAPP_URL`:
   - Գործարկեք բոտը՝
     ```bash
     npm run bot
     ```
   - Երբ օգտատերը բոտին ուղարկի `/start`, կստանա գեղեցիկ ինլայն կոճակ, ինչպես նաև ներքևի ձախ անկյունում կհայտնվի **«📍 Մոտակա Մարդիկ»** կոճակը:
